# Steering — Product

HAUNT is a haunted-house escape game built for Kiroween 2026 (Costume Contest).

**What it is:** one excellent core loop — explore a procedurally generated manor, collect 3 relics, escape before your sanity runs out, while an AI ghost narrates and hunts you.

**What it is not:** a feature hub, a multiplayer game, a SaaS, or a tech demo of many half-features. If a feature does not make the escape loop scarier, tenser, or more fun, cut it.

**Player promise:** open the page and be playing within 10 seconds, with zero setup, zero account, zero key. The spooky UI must *enhance* the function (darkness is a mechanic, fog is information, flicker is feedback) — never decoration for its own sake.

**Tone:** gothic, second person, present tense. The Warden never breaks character and never mentions being an AI.

**Quality bar:** genuinely fun, polished, bug-free. A judge who has never seen the game must be able to finish a full escape run without instructions beyond the on-screen hints.
