# HAUNT — Design

## Architecture (static, zero backend)

```
index.html          — shell, canvas, HUD, menus, settings (API key field)
css/haunt.css       — all styling: fog, flicker, typography, HUD, menus
js/
  rng.js            — seeded PRNG (mulberry32) + string-seed hash (xmur3)
  manor.js          — procedural manor generator (rooms, corridors, doors, keys, relics, exit)
  warden.js         — Warden patrol AI (waypoints, line-of-sight, chase/flee states)
  narration.js      — offline templated narration engine + OpenRouter client (optional key)
  audio.js          — WebAudio ambience (wind noise, creaks, heartbeat), mute toggle
  game.js           — game loop, input, collision, sanity/oil, win/lose, leaderboard
  render.js         — canvas rendering: tiles, fog of war, candlelight gradient, entities
tests/
  manor.property.test.js — property tests (node --test): determinism, connectivity, solvability
  playtest.js       — scripted playthrough harness (20 seeds, headless, 0 errors)
```

No framework, no build step, no bundler. `node --test` for tests. Everything runs from `file://` or GitHub Pages.

## Manor generation (seeded, always solvable)

- Grid-based: manor is a rectangular grid (e.g. 28×20 tiles). Rooms placed by BSP/random-rect packing, connected by L-shaped corridors.
- **Solvability by construction:** generate rooms → connect with a spanning tree of corridors (guarantees full connectivity) → place exit in the farthest room from spawn → place 3 relics in 3 different rooms reachable from spawn → place locked doors only on branches that have their key placed earlier on the main path (key room is reachable without passing its own door).
- **Verification:** after generation, run BFS from spawn over the walkable graph with the key/door logic simulated; reject and re-roll (same seed + attempt counter) if any relic/exit/key is unreachable. Property tests assert this for many seeds.
- Room types: Foyer, Library, Kitchen, Chapel, Cellar, Bedroom, Gallery, Study — each with its own narration flavor, props, and puzzle flavor.

## Game systems

- **Player:** tile-based movement with smooth interpolation; light radius ~4.5 tiles (lantern), 2.5 tiles without oil.
- **Sanity (0–100):** drains 1/s in darkness, 3/s when the Warden is within 6 tiles and visible, +15 on entering a lit safe room (candle rooms), −10 on a scare event. At 0 → game over.
- **Oil (0–100):** drains 1/s while lantern is on; candles found in rooms restore +30. Lantern toggle (L key) — darkness is dangerous but oil is scarce.
- **Warden:** patrols waypoints between rooms; if the player is within line-of-sight (Bresenham, no wall between) and ≤5 tiles, it chases for 4s; contact within 1 tile costs 15 sanity and knocks the player back 2 tiles. Heartbeat audio scales with distance.
- **Puzzles:** (a) riddle doors — answer a riddle (3 choices) to open; wrong answer costs 5 sanity; (b) key doors — find the matching key; (c) relic pedestals — collect by standing on them for 1s while the Warden's whisper warns you.
- **Win:** collect all 3 relics, then reach the exit door. Timer recorded; best time per seed saved locally.

## Narration engine

- **Offline engine:** template banks keyed by (room type × event). Events: enter_room, relic_found, door_locked, riddle_wrong, warden_spotted, sanity_low, oil_low, escape. Each bank has ≥6 variants; selection is seeded by (seed + event count) so replays vary but stay deterministic per run.
- **OpenRouter path:** when a key is present, the Warden's line for an event is generated by a free model with a system prompt ("You are the Warden, a cruel ghost... one or two sentences, gothic, second person"). 6s timeout, one in-flight request max, queue coalescing (latest event wins). Any failure → offline line, no error shown.
- **Voice of the Warden:** all lines in second person, present tense, gothic. Never breaks character, never mentions being an AI.

## Rendering & audio

- Canvas 2D, tile size 32px, camera follows player. Fog of war: unexplored tiles black; explored-but-unlit tiles dim; lit radius rendered with a radial gradient + flicker (noise on radius/intensity).
- Entities drawn as simple vector glyphs (player: hooded figure; Warden: pale wisp with trailing shroud; relics: glowing artifacts) — no external image assets, so the game works offline.
- Particles: dust motes in light, fog wisps drifting across the screen (CSS overlay), occasional lightning flash on scare events.
- Audio: WebAudio-generated (no audio files): filtered noise for wind, random creak oscillators, heartbeat (sine thump) rate tied to Warden distance. Master mute button + `M` key.

## Testing

- **Property tests** (`tests/manor.property.test.js`, `node --test`): for seeds 0..N — determinism (same seed → identical manor), connectivity (all rooms reachable), solvability (relics + exit + keys reachable with key ordering), relic placement (3 distinct rooms, none in spawn room), door/key pairing (every locked door has its key placed before it on the path).
- **Playtest harness** (`tests/playtest.js`): headless driver (jsdom-free — pure logic simulation using the same game modules in Node with a DOM stub) that plays 20 seeds with a simple solver policy (BFS to nearest objective), asserts: no exceptions, game reaches win state, sanity never goes negative without game-over, timer recorded. Log to `tests/playtest-log.md`.
